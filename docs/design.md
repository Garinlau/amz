# 亚马逊作图工作台 · 设计

> 只在电脑上使用。先做服装，先在公司局域网里跑通。运营和审核是同一个人。

## 一、结构：一个产品一行，一个颜色一行

```
产品（一个产品一行）
 ├─ 图位（这个产品的每张图：主图1~9、A+模块、品牌故事。每张图只设计、审核一次，所有颜色共用）
 └─ 颜色套图（一个颜色一行。点「出整套图」，用这个颜色的白底图把已确认的主图一次出齐）
A+ 和品牌故事所有颜色共用一套，直接在「图位」那一行出图。
```

另外 4 张辅助表：使用说明、模特库、尺寸规格、套图模板（新产品点「生成图位」时按它建图位）。

## 二、流程

1. **建产品**：在「产品」表加一行，选模特，点「生成图位」→ 程序按套图模板建好主图1~8、A+ 等图位。
2. **加颜色**：「颜色套图」表每个颜色一行，上传我们自己的白底产品图。
3. **放参考图**：在「图位」表每个图位放竞品参考图，勾选「参考什么」。
4. **读图**：产品上点「整套读图」（或单个图位点「读图」）→ AI 写出画面描述、建议、中英文出图说明 → 状态「待审核」。
5. **审核**：在「待审核」视图里改「出图说明（中文）」，点「确认」。中文改过的，出图前程序自动重新翻成英文。
6. **出主图**：「颜色套图」里点某个颜色的「出整套图」→ 结果放进「主图1结果」~「主图9结果」。建议先出主推色。
7. **验收**：满意点「通过」；不满意在「要重做的图」勾上图位、写验收意见，点「重做选中的图」，只重做勾上的。
8. **A+ / 品牌故事**：在图位那一行点「A+出图」，用主推色的白底图（多色展示用所有颜色）。

按钮点一下只是改「状态」或「指令」，局域网里的后台程序每 30 秒看一次表格，看到就去做。
按钮和自动提醒要在飞书里手动加一次，见 `docs/飞书手动设置.md`。

## 多维表格特性的用法

| 特性 | 用在哪 |
| --- | --- |
| 按钮 + 自动化 | 所有操作都是点按钮，「状态」只做显示，不用手动选 |
| 视图 | 图位按产品分组；「待审核」只露审核要看的栏目；「待验收」用画册大图看结果；进度看板 |
| 关联 | 产品 ↔ 图位、产品 ↔ 颜色套图、产品/颜色 → 模特库 |
| 自动提醒 | 待审核、待验收、出错时发飞书消息 |
| 栏目说明 | 每个栏目都写了一句提示，鼠标移上去能看到 |

## 亚马逊图片要求（查到的）

**服装主图（第 1 张）**
- 背景必须纯白（RGB 255,255,255），浅灰也不行。
- 成人服装要穿在真人模特身上，模特必须站立（不能坐、跪、靠、躺）。
- 只出现在售商品，衣服占画面 85% 以上，不能有文字、标志、水印。
- 官方服装指南：长边至少 1600 像素（才能放大看），比例接近 3:4（宽:高）。

**附图（第 2–9 张）**：场景、坐姿、细节、搭配都可以，但要和实物一致。

**A+**：高级 A+ 全图模块电脑端 1464×600、手机端 600×450；品牌故事 1464×625；单张 2MB 以内，JPG 或 PNG。

**⚠ 2026 年新规：AI 生成的人要打标记**
- 从 2026 年 6 月起，图里如果有“完全由 AI 生成、看起来像真人”的人，上传前必须在图片文件里写入标记
  `contains-synthetic-performer`（写在图片信息里，看不见，不影响画面）。亚马逊会在页面上提示顾客。
- 真人照片只是用 AI 修过的，不需要标。
- 我们的模特都是 AI 生成的，所以**程序会在出图时自动写入这个标记**。
