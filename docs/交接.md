> 写于 2026-09-27。代码在 GitHub `Garinlau/amz` 的 `claude/amazon-image-workbench-design-zfbq78` 分支。

## 一、要做的东西（一句话）

用**飞书多维表格**当工作台，做亚马逊服装图片：运营在表格里放竞品参考图 → AI 读图、写出图说明 → 人审核 → AI 按我们自己的白底产品图出图 → 结果回到表格验收。先用服装跑通，先在公司局域网部署。

## 二、已经和用户确认过的决定（不要再改）

| 事项 | 决定 |
| --- | --- |
| 使用方式 | 只在电脑上操作表格，不考虑手机操作 |
| 表格结构 | **一个产品一行**（产品表），**一个颜色一行**（颜色套图表），每张图的设计放在「图位」表 |
| 多颜色 | 同一产品的所有颜色用**同一套设计**，只换衣服颜色。每张图只设计、审核一次 |
| 主图 / A+ | 主图每个颜色出一整套；A+ 和品牌故事所有颜色共用一套 |
| 操作方式 | 用**按钮**，不让人手动改状态 |
| 人员 | 运营和审核是**同一个人**，暂不需要权限区分 |
| 衣服依据 | 我们提供白底产品图，出图时衣服必须和白底图一致 |
| 参考图 | 竞品图，只借鉴运营勾选的方面（姿势、场景等），不照搬人和衣服 |
| 图上文字 | **一律不生成**。AI 优化的英文文案单独存一栏，给后期排版用 |
| 模特 | 内置常用模特（金发白人、墨西哥裔黑发/棕发等），每次由 AI 结合需求写出完整描述 |
| 文案语言 | 英文（美国站） |
| 审核语言 | 审核人改**中文**出图说明，程序自动翻成英文再出图 |
| 读图模型 | 先试本地 Grok、DeepSeek，都可配置 |
| 出图模型 | 先试 Nano Banana（谷歌）、本地部署的 GPT Image 2.5，都可配置 |
| 部署 | 先在局域网跑通（公司也有腾讯云服务器，后面再说） |
| 出图尺寸 | 默认 1569×2560（和下载的竞品图一样）；官方建议的 3:4（1600×2134）作为备选，在「尺寸规格」表里切换 |

## 四、本地要做的事（按顺序）

### 第 1 步：拿代码、装环境

```bash
git clone https://github.com/Garinlau/amz.git
cd amz
git checkout claude/amazon-image-workbench-design-zfbq78
pip install -r workbench/requirements.txt
python -m pytest -q tests        # 应该 8 passed
```

### 第 2 步：选机器人、配权限

- 用「极值」或「Codex」机器人（两个项目里已有的飞书自建应用），**二选一**。
- 在飞书开放平台确认这个应用开了以下权限，没开就加上并发布新版本：
  - 多维表格：查看、编辑、新建（`bitable:app`）
  - 云文档：上传、下载文件；管理协作者（`drive:drive`）
- 把应用编号和密钥放进环境变量（**不要写进任何文件，不要提交到仓库**）：

```bash
export FEISHU_APP_ID=cli_xxx
export FEISHU_APP_SECRET=xxx
```

### 第 3 步：建表

```bash
cp workbench/config.example.toml workbench/config.toml
python -m workbench.setup_base --dry-run                                   # 先看看会建什么
python -m workbench.setup_base --share-email 你的飞书账号邮箱 --demo          # 真正建
```

- 会建 7 张表、预置数据、4 个视图，外加一个示例产品（阔腿裤，已建好 12 个图位和 2 个颜色）。
- 结束时会打印 `app_token`，填进 `workbench/config.toml` 的 `[feishu] app_token`。
- 结束时打印的「还要手动设」清单，照着在飞书里补。
- **如果机器人建的表你打不开**：`--share-email` 要填飞书账号绑定的邮箱；不行就换 `--share-openid`，或加 `--folder 文件夹token` 让它建在你的云盘文件夹里（机器人要先有这个文件夹的编辑权限）。

### 第 4 步：在飞书里手动加按钮（约 10 分钟）

照 `docs/飞书手动设置.md` 做：10 个按钮 + 3 个自动提醒 + 检查视图（图位按产品分组、看板按状态分组）。

然后**让用户打开表格看一遍**，重点看会不会有看不懂、容易点错的地方。这一步是用户上次提出的核心诉求。

### 第 5 步：配模型，先跑读图

编辑 `workbench/config.toml` 里的 `[vision]` 和 `[image]`：
- 本地 Grok 的地址和型号名；DeepSeek 要选**能看图**的型号（普通的 deepseek-chat 可能不能看图）
- Nano Banana 的型号名以谷歌当前文档为准；本地 GPT Image 2.5 的地址
- 各模型的密钥同样放环境变量（名字见 config 里的 `api_key_env`）

```bash
export GROK_API_KEY=... GEMINI_API_KEY=...   # 按实际用到的
python -m workbench.worker --once            # 只跑一轮，方便看日志
```

测试顺序：
1. 示例产品的「阔腿裤-主图2」已有参考图，在那一行点「读图」→ 跑 `--once` → 看状态变「待审核」、AI 栏目有内容
2. 给「阔腿裤-黑色」上传白底图；把主图1、主图2 点「确认」
3. 在「阔腿裤-黑色」点「出整套图」→ 跑 `--once` → 看「主图1结果」「主图2结果」出图
4. 没问题后长期运行：`python -m workbench.worker`（每 30 秒看一次表格）

### 第 6 步：长期运行

放到局域网那台常开的电脑上（极值项目跑在 fnos 上，可参考它用 systemd 用户服务托管的做法）。

## 五、第一次连真飞书时可能要修的地方

这些是按飞书文档写的，没实测过，出错先看这里：

| 位置 | 可能的问题 | 处理办法 |
| --- | --- | --- |
| `setup_base.create_table` | 建表时带「栏目说明」（description）飞书可能不认 | 程序已有兜底：失败会改成逐个栏目建、去掉说明 |
| `setup_base.create_table` | 建表时一起带关联栏目可能失败 | 同上，逐个栏目建 |
| `setup_base.create_views` | 视图筛选的写法（`filter_info` 里 value 的格式）可能不对 | 失败只会提示手动设，不影响其它 |
| `feishu.search_records` | 按状态筛选：`operator: is` + `value: [选项名]` | 如果筛不出来，改成不带筛选拿全部行、在程序里过滤 |
| `feishu.text_of / link_ids` | 读出来的格子格式（文本是分段列表、关联是 `link_record_ids`） | 打印一行原始数据对照修改 |
| `feishu.download_attachment` | 表格附件下载，开了高级权限的表可能要带 `extra` 参数 | 暂时别开高级权限 |
| `worker.do_product` | 清空「指令」时传的是 `None` | 如果飞书不接受，改成传空字符串或删掉这个键 |
| `models._gemini` | 型号名、`imageConfig` 参数名以谷歌当前文档为准 | 改 `config.toml` 或 `models.py` |
| `models._openai_images` | 本地 GPT Image 是否兼容 `/images/edits` 多图输入 | 按本地服务的接口改 |
| `imaging.to_jpeg` | AI 人物标记写在图片信息里（`contains-synthetic-performer`） | 用 exiftool 查：`exiftool -XMP-dc:Subject 图.jpg` |

## 六、还没定的事（需要问用户）

1. **套图模板**：现在默认 8 张主图 + 3 个 A+ 模块 + 品牌故事（按两份旧 PPT 归纳）。用户常用的一套是不是这样？改「套图模板」表即可，不用改代码

4. **一个产品一个模特**：个别颜色想换人可以在颜色套图里填「换模特」，是否够用

## 七、重要提醒

- ⚠ **仓库是公开的**，里面有竞品图和作图方案，建议改成私有
- ⚠ **亚马逊 2026 年 6 月起的新规定**：图里有完全由 AI 生成的真人样貌的人，上传前要在图片信息里写入 `contains-synthetic-performer` 标记。程序已自动写入（面料特写这种没人的图不写）。上传前不要用会清掉图片信息的工具再处理
- 白底主图要求：纯白背景、模特站立、衣服占画面 85% 以上、无文字。坐姿只能用在第 2 张以后

## 九、状态流转速查

**图位**：未开始 →（读图）读图排队 → AI 读图中 → 待审核 →（确认）已确认
　　A+/品牌故事继续：→（A+出图）出图排队 → AI 出图中 → 待验收 →（A+通过）已通过 /（A+重做）重做排队

**颜色套图**：未开始 →（出整套图）出图排队 → AI 出图中 → 待验收 →（通过）已通过 /（勾图位 + 重做选中的图）重做排队

**产品**：指令栏 =「生成图位」或「整套读图」，程序做完清空，结果写在「程序提示」

任何一步出错 → 状态「出错」，原因在「程序提示」，改好后再点一次对应按钮。
