# 飞书里需要手动设置的部分（约 10 分钟）

建表程序能建好表、栏目、预置数据和大部分视图。**按钮和自动提醒**飞书不允许用程序创建，要在表格里手动加一次。
加好之后，平时只需要点按钮，不用手动改「状态」。

> 没加按钮也能用：直接把「状态」或「指令」改成下表里的值，效果一样。按钮只是更顺手、更不容易选错。

## 一、加按钮（共 10 个）

每个按钮的做法都一样：

1. 打开对应的表，点最右边栏目标题旁的「+」，新增栏目，类型选 **按钮**。
2. 栏目名填下表的「按钮名」，按钮文字也填同样的字。
3. 点击动作选 **触发自动化**，新建一个自动化流程：
   - 触发条件：**点击按钮**（选刚建的这个按钮）
   - 执行操作：**修改记录** → 修改「触发的这条记录」→ 把「要改的栏目」设成「改成」的值
4. 保存并启用。

| 表 | 按钮名 | 要改的栏目 | 改成 |
| --- | --- | --- | --- |
| 产品 | 生成图位 | 指令 | 生成图位 |
| 产品 | 整套读图 | 指令 | 整套读图 |
| 图位 | 读图 | 状态 | 读图排队 |
| 图位 | 确认 | 状态 | 已确认 |
| 图位 | A+出图 | 状态 | 出图排队 |
| 图位 | A+重做 | 状态 | 重做排队 |
| 图位 | A+通过 | 状态 | 已通过 |
| 颜色套图 | 出整套图 | 状态 | 出图排队 |
| 颜色套图 | 重做选中的图 | 状态 | 重做排队 |
| 颜色套图 | 通过 | 状态 | 已通过 |

加好后，把按钮栏目拖到每张表靠前的位置（名称后面），打开表格就能看到。

## 二、自动提醒（建议加 3 个）

新建自动化 → 触发条件选 **当记录满足条件时**，执行操作选 **发送飞书消息**，发给你自己：

| 表 | 条件 | 消息内容建议 |
| --- | --- | --- |
| 图位 | 状态 = 待审核 | 「{名称} AI 读完了，去审核」 |
| 颜色套图 | 状态 = 待验收 | 「{名称} 整套图出好了，去验收」 |
| 颜色套图 / 图位 | 状态 = 出错 | 「{名称} 出错了：{程序提示}」 |

## 三、检查视图

建表程序会自动建下面这些视图。如果某个视图的筛选没设上，程序结束时会提示，按提示手动补：

| 表 | 视图 | 设置 |
| --- | --- | --- |
| 图位 | 全部 | 按「产品」分组（需要手动设：视图右上角「分组」→ 产品） |
| 图位 | 待审核 | 筛选 状态 = 待审核；只显示审核要看的栏目 |
| 图位 | A+待验收 | 画册视图，筛选 状态 = 待验收，封面选「A+成品」 |
| 颜色套图 | 待验收 | 画册视图，筛选 状态 = 待验收，封面选「主图1结果」 |
| 颜色套图 | 进度看板 | 看板视图，按「状态」分组（需要手动设） |

## 四、权限（可选）

目前运营和审核是同一个人，不需要设权限。以后如果分开，可以用「高级权限」把「状态」「程序提示」「出图次数」和各个「结果」栏设成只读。
